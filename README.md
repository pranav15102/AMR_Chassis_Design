# Modular AMR Base Chassis – for Indoor Navigation & Sensor Integration

## 🛠️ Problem Statement
Conventional AMR chassis are bulky and inflexible. A lightweight, modular design was needed for sensor-heavy, dynamic environments.

## ✅ Solution
Designed a symmetric, 3D-printable base chassis with custom slots for sensors, compute, and batteries.

## 🧠 Technical Approach
- Designed in SolidWorks with LiDAR/camera/compute slots
- Support-free geometry for FDM printing
- Cable routing and ventilation slots included
- Front differential drive + rear caster for maneuverability

## 📊 Key Outcomes
- Stable weight distribution under load
- Supports PLA, acrylic, or aluminum manufacturing
- Deployed in real-world AMR navigation experiments
